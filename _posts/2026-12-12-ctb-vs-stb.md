Plot styles decide what your linework looks like on paper: how thick, how dark, what color. AutoCAD has two completely different ways of doing that, both still in use, and a drawing can only use one of them at a time.

## Two systems

**Color-dependent (CTB).** The plot style table maps each of the 255 AutoCAD colors to pen settings. Color 1 might plot black at 0.35 mm, color 8 at 50% screening. The color of an object decides how it plots.

**Named (STB).** The plot style table holds styles with names, like "Heavy" or "Screened 50%", and you assign them to layers or objects. Color is just color; the plot style is a separate property.

CTB comes from the pen-plotter days, when each pen in the carousel was literally a color. It's simple and it's everywhere. Named styles came later, so that color could go back to being for the screen. Plenty of agencies and firms standardized on one or the other years ago and have stayed there, which is why you'll get handed both.

## How to tell which a drawing uses

Type `PSTYLEMODE` at the command line. It's read-only:

- `1` = color-dependent (CTB)
- `0` = named (STB)

The quick visual check: in the Layer Properties Manager, the **Plot Style** column is greyed out in a CTB drawing and editable in an STB drawing. The page setup tells you too: a CTB drawing only lists `.ctb` files.

## Converting

Two commands, and they do different things:

- `CONVERTCTB` turns a **CTB file** into an **STB file** with one named style per color, so a converted drawing can plot the same way it did.
- `CONVERTPSTYLES` switches the **drawing** between the two modes. Going to named, it asks for an STB to attach (the one you just made, usually).

After converting, check:

- **Layer plot styles.** Layers get named styles based on their old color. Make sure they make sense, and clean up anything you'll never use.
- **Page setups and sheet sets.** Every layout's page setup needs to point at the new table, including the ones in the sheet set template.
- **Xrefs.** Keep every drawing in a set in the same mode. Mixed modes are a reliable source of "why is this plotting grey" at 4:30 on submittal day.

Convert a copy, plot both versions to PDF, and compare them before replacing anything.

## Templates

The mode is baked into a drawing when it's created. A new drawing gets its mode from the template (and `PSTYLEPOLICY`, for drawings started without one). That's why the real decision happens once, when the template is built. Flipping a project halfway through means touching every drawing, layout and page setup in it.

If you're building a template for a client or agency, use whatever their CAD standard says. If nobody says, ask what the sheets will be plotted with downstream before you pick.

## My take

For my own templates I'd go named: color is free to mean "existing vs proposed" on screen, and the plot style lives where it belongs, on the layer. But a good CTB template plots exactly as well as a good STB one. The worst setup is the one where half the project uses each. Pick one, write it into the template, and don't convert casually.
