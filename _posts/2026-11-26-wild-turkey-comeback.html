Thanksgiving had me thinking about turkeys. The wild kind, not the one in the oven. Turns out there’s a sixty-year federal data set that counts them, and I couldn’t help myself.

Every June since 1966, volunteers have driven the same roadside routes across North America, stopping every half mile for three minutes to count every bird they see or hear. That's the North American Breeding Bird Survey, run by the USGS and the Canadian Wildlife Service, and it's one of the longest-running wildlife data sets anywhere.

It's also a front-row seat to one of the biggest wildlife comebacks in the country. In the late 1960s, a wild turkey turned up on about 2% of US survey routes in a given year. Now it's about 30%.

Here's every route in the lower 48, decade by decade. Press play to animate the progression.

What you're looking at

Gray dots are routes that were surveyed but didn't count a turkey; pink ones did, and the darker the pink, the more turkeys per survey. In the 1960s and '70s the pink is scattered across a few southern and Appalachian strongholds. By the 2000s it fills in the Northeast, the Midwest and the Plains.

That isn't natural drift. Turkeys had been hunted and logged out of most of their range by the early 1900s, and state wildlife agencies spent decades trapping birds where they survived and releasing them where they didn't. The survey caught that work as it paid off. Some of the biggest swings are in places that had essentially none: Massachusetts went from 1.5% of surveys in the 1970s to 66% in the last decade, Wisconsin from 0.2% to 63%, and Maine from zero to 36%. If you've ever been stared down by a turkey in a New England parking lot, now you know who to thank.

The line also shows where the story is now. The climb flattened out around 2005, and it's been bouncing between about 24% and 31% since. State biologists have been reporting declines in some areas, and a flat line in a survey this coarse is consistent with that. Don't read too much into a single year: no survey ran in 2020, and the number of routes surveyed changes every year.

How it's built: CSV → PostGIS → map

Same idea as the Waffle House map, with a real database in the middle this time. Bigger bird, bigger data. The raw data is about 7.5 million rows: every species counted on every route in every year. PostGIS does the heavy lifting, and the page gets only the summaries.

1. Load it

The USGS release ships a Routes.csv (one row per route, with the start point's latitude and longitude) and a zip of per-state count files. psql's \copy loads them straight from disk, and each route's start point becomes a real geometry:

{% highlight sql %} \copy bbs.routes FROM 'Routes.csv' WITH (FORMAT csv, HEADER true, ENCODING 'LATIN1') ALTER TABLE bbs.routes ADD COLUMN geom geometry(Point, 4326); UPDATE bbs.routes SET geom = ST_SetSRID(ST_MakePoint(longitude, latitude), 4326); {% endhighlight %}

2. Ask a spatial question

The survey uses its own numeric state codes, so rather than track down a lookup table, let geometry answer it: which state polygon is each route's start point inside? (A dozen routes start right on the coast, just outside the simplified outlines, so they get the nearest state instead.)

{% highlight sql %} UPDATE bbs.routes r SET state_name = s.name FROM bbs.us_states s WHERE ST_Intersects(r.geom, s.geom); {% endhighlight %}

3. Count the zeros

The one real trap in this data: the count files only list species that were seen. A route surveyed with no turkeys has no turkey row at all, and if you average only the rows you have, every route looks like it had turkeys. So first build the list of every survey run, then left-join the turkey counts onto it and fill the gaps with zero. Wild Turkey is species code 3100:

{% highlight sql %} CREATE TABLE bbs.runs AS SELECT DISTINCT route_id, year FROM bbs.counts WHERE rpid = 101; -- standard runs only CREATE TABLE bbs.turkey_runs AS SELECT ru.route_id, ru.year, COALESCE(c.species_total, 0) AS turkeys FROM bbs.runs ru LEFT JOIN bbs.counts c ON c.route_id = ru.route_id AND c.year = ru.year AND c.rpid = 101 AND c.aou = 3100; {% endhighlight %}

4. Summarize, export, draw

From there it's ordinary GROUP BYs: share of routes with a turkey per year, average per route per decade, and each state then and now. Those go out as CSVs, and a small Node script projects the route points onto a US map and writes both the file this page draws and the SQLite file for Datasette. All the scripts are in the site's repo under tools/posts/wild-turkey-comeback/.

A caveat for the bird people: these are simple averages of raw counts, not the USGS's model-based trend estimates, which correct for things like observer changes and which routes got run. The shape matches the published trend, but treat the exact numbers as a rough guide.
